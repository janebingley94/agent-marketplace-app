## 技术栈详情

### 前端
- **框架**: Next.js 14 (App Router) + TypeScript
- **UI**: Tailwind CSS + shadcn/ui
- **状态管理**: TanStack Query + Jotai + nuqs
- **钱包**: wagmi + viem (EVM)
- **图表**: Recharts
- **表格**: TanStack Table

### 后端
- **框架**: NestJS + TypeScript
- **数据库**: PostgreSQL + Prisma
- **缓存**: Redis
- **队列**: BullMQ (延后)
- **搜索**: PostgreSQL全文搜索 (MVP)
- **监控**: OpenTelemetry

### 基础设施
- **容器化**: Docker Compose (PostgreSQL, Redis)
- **CI/CD**: GitHub Actions
- **包管理**: pnpm + Turborepo
